# KNOT & BLOOM ⚜
### *“Discover Something Worth Keeping.”*
**Handcrafted Crochet Artisan Portfolio & Bespoke Studio**

Knot & Bloom is an exclusive handcrafted crochet atelier showcase. Built with Next.js 14, Tailwind CSS, TypeScript, and Prisma, it features an editorial, museum-grade aesthetic honoring the delicate discipline of hand-hooked fiber arts.

Every creation at Knot & Bloom is **100% Handcrafted Crochet** — patiently hooked by master artisans using premium natural cotton yarns and specialty fibers.

## 🏛️ Storefront Architecture & Pages

1. **Home (`/`)**: Cinematic video hero, curated craft collections, category boutique showcase, artisan storytelling, and verified customer testimonials.
2. **Creations Portfolio (`/shop`)**: Filterable artisan portfolio with category boutique selector, material search, and direct commission triggers.
3. **Creation Details (`/product/[slug]`)**: Multi-angle photo gallery, craft specifications, yarn details, care rituals, and one-tap WhatsApp / direct email inquiry box.
4. **Bespoke Inquiries & Concierge (`/contact`)**: Interactive custom commission inquiry form with direct WhatsApp contact and email.
5. **Saved Favorites (`/wishlist`)**: Save favorite creations and initiate custom crafting requests.
6. **About Knot & Bloom (`/about`)**: The artisan manifesto and guiding principles of handcrafted fiber art.
7. **Knowledge & FAQ (`/faq`)**: Care rituals, yarn durability, and bespoke crafting timelines.

## 🚀 Quick Start Guide

### Prerequisites
- Node.js 18+ or 20+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ts833839-jpg/Knot-Bloom.git
cd Knot-Bloom

# Install dependencies
npm install

# Initialize database
npm run prisma:generate

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.
